\caption{\textbf{Detection, repetition within responses, and diversity
between responses.} Each method generates two 1,024-token responses
for each of 50 prompts using Qwen3-8B-Base at temperature 1 with the
full vocabulary. Self-BLEU measures average overlap in wording between
the two responses to each prompt; lower values indicate greater
between-response diversity. Repeated 4-grams is the percentage of
contiguous four-token sequences that have already appeared earlier in
the same response, counting every occurrence after the first.
Distinct-3 is the number of distinct contiguous three-token sequences
divided by the total number of three-token sequences in a response;
higher values indicate less repetition. Both metrics include
overlapping sequences and are averaged over the 100 responses.
TPR is the percentage of watermarked responses detected. Each detector
uses only the generated response and targets a false-positive rate of
$0.1\%$. With repeat fallback on, SynthID, TextSeal, and Gumbel-Max
use unwatermarked sampling at positions where the watermarking context
repeats within a response. With it off, they continue applying the
watermarking rule at those positions. Settings for the PRC watermark:
online generation, $\eta=0.05$, check weight $t=3$,
row rate $99/100$, and posterior-mean/Hoeffding detection.}
